## 可复用的验收原则

1. 在隔离的授权环境中，通过 MCP 的 `tools/list` 确认所需工具可用。
2. 先对无目标的输入验证参数校验、错误语义和不产生副作用，再对授权 DUT 验证最小业务链。
3. 对可能改变代理配置、范围、历史或持久化状态的工具，预先定义清理与回退步骤。
4. 记录当期工具版本、权限、输入摘要和回执，但将这些记录留在私有工作区，不提交公开仓库。

该检查点不能替代当前环境的重新验收。
