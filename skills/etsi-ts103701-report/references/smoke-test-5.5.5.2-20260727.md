# 5.5-5-2 回归样例（已匿名化）

> 这是一个历史工作流样例，不是某台设备的检测报告，也不能作为任何 DUT 的证据。
> 2026-09-12 已移除真实设备型号、版本、地址、会话标识、时间线和端点统计。

## 保留的回归目标

1. 从代理历史中选择候选端点；不得把历史请求、认证头或原始响应提交到公开仓库。
2. 对每个候选端点执行受控 `auth_diff`，比较已认证与未认证结果。
3. 仅在原始产物、工具收据与条款证据可索引时生成结论；否则输出 `INCONCLUSIVE`。
4. 任何公开回归 fixture 都必须使用合成主机名、示例凭据和零敏感 Payload。

此文件只说明回归意图。可执行规则以 `auth-diff-workflow.md`、`verdict-criteria.md` 和当前
Pipeline 代码为准。
